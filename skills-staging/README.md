# Staged skills (not loaded)

These are intentionally outside `skills/` so the plugin does not load them.

- `needs-adaptation/`: wanted, but tied to one host or an external tool. Adapt, then move into `skills/`.
- `alternatives/`: upstream skills that overlap an active skill. Use them for A/B runs in `evals/`; do not enable both at once.

See `docs/porting-notes.md`.
